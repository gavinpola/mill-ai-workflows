How it works

The system uses a Facilitator agent (Opus) to orchestrate specialized workers. Research agents gather competitive intelligence and company data in parallel. The Deck Builder generates reveal.js presentations following consistent design principles. A "Harry Tannenbaum" reviewer persona provides quality feedback before human review. All prompts, frameworks, and outputs are documented for reuse by Mill's team.
