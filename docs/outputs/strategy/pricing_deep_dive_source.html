Value Strategy: The Complete Picture

Mill's value isn't one thing—it's a stack. Operational savings, insights, compliance, enterprise economics. Each layer compounds. Here's how they fit together.

The Value Stack

The previous framing: "Mill helps you understand waste and reduce food costs by 15-25%." True, but incomplete. It misses the physical value (trash cost reduction), ignores compliance needs, and treats enterprise deals like scaled-up single locations.

The complete picture: Four value layers that stack. Each builds on the previous. The highest-value customers get all four.

Layer 1: Operational Savings Immediate, certain
$250-500/month in trash costs
Mill dehydrates food waste, reducing weight and volume by ~80%. Less waste = fewer pickups, smaller dumpsters, lower hauling fees. This isn't "insights"—it's physics. The savings start on day one and continue as long as the unit is there.
Layer 2: Insights Value Medium-term, behavior change required
15-25% food cost reduction over time
Know what's wasted, when, why. Optimize purchasing, prep, portions. The 15-25% range is consistent with results reported by Winnow, Leanpath, and industry studies. But this isn't "learn once and leave"—staff turns over, menus change, seasons shift. Continuous optimization requires continuous data.
Layer 3: Compliance Value For regulated segments
+$200/month premium for documentation
California SB 1383 mandates organic waste diversion from landfills. Enforcement began 2024 with penalties up to $10K/day for repeat violations. ESG reporting increasingly requires verified data. Mill provides automated, audit-ready documentation—verified by physical processing, not self-reported. For regulated customers, Mill is a compliance solution, not just a cost saver.
Layer 4: Enterprise Value For multi-location customers
Centralized visibility, benchmark, strategic lock-in
500 locations isn't 500× one location. It's centralized visibility across all sites, cross-location benchmarking, one vendor relationship. The switching cost isn't "remove a unit"—it's "replace enterprise infrastructure."

Why this matters for retention: The "learn and churn" risk is real for insights alone. But a customer who "learned" their waste patterns still saves on trash (Layer 1), needs compliance documentation (Layer 3), and loses centralized visibility (Layer 4). Each layer mitigates churn.

Layer 1: Trash Cost Reduction

This is the foundation—and it's been missing from the value story. Mill physically reduces waste volume. That has immediate, measurable impact on trash costs.

The Physics

Food waste is heavy (high water content) and decomposes quickly (smells, attracts pests). Mill dehydrates it, reducing weight and volume by approximately 80% (based on consumer unit specifications; commercial unit validation required). What was a full bin of wet, heavy food scraps becomes a small bag of dry material.

Why This Changes the Value Proposition

The strategic insight: Trash savings are the floor that justifies the base fee. Even if a customer never acts on insights, they're still cash-flow positive. This transforms the value proposition from "maybe saves money" to "definitely saves money, probably saves more."

Enterprise-Specific Value

Things enterprise customers get that single locations don't:

  • Centralized visibility: Corporate sustainability team sees all 500 locations in one dashboard
  • Cross-location benchmarking: Identify which locations are outliers, why, and fix it
  • Best practice rollout: When one location finds something that works, standardize across all
  • Aggregate reporting: One ESG report covering all facilities, not 500 separate data pulls
  • Procurement leverage: See waste patterns across all locations to negotiate with suppliers

What Creates Retention

The "learn and churn" concern is valid for insights alone. But the full value stack has multiple retention mechanisms.

Mechanism Why It Creates Retention
Trash savings (Layer 1) Savings continue regardless of whether they "learned" anything. Cancel = lose the savings.
Physical hardware Unit is installed. Removing it requires labor and disruption.
Compliance documentation (Layer 3) If they're using Mill for SB 1383 compliance, leaving means building a new system.
Enterprise centralization (Layer 4) Leaving means losing cross-location visibility, benchmark data, aggregate reporting.
Compounding predictions 12 months of location-specific data improves accuracy. Leaving = starting over.

The Customer Who "Learned" Their Waste Patterns Still:

  • Saves $300-500/month on trash costs (ongoing)
  • Needs compliance documentation (if regulated)
  • Loses centralized visibility (if enterprise)
  • Has to physically remove the unit
  • Loses historical data for predictions

Net: Single-location, non-regulated customers have the highest churn risk. Enterprise customers with compliance needs have the lowest. Prioritize accordingly.

Pricing Structure

The pricing should reflect the value stack. Base fee covers operational value. Modules add compliance and enterprise tiers. Outcome share captures upside from insights.

Component Amount What It Covers
Base fee $500-700/month Hardware, trash savings, basic insights dashboard. Justified by Layer 1 alone.
Compliance module +$200/month Automated SB 1383 documentation, ESG reporting integration, audit-ready exports.
Enterprise tier +$100-200/month Centralized dashboard, cross-location benchmarking, API access, dedicated support.
Outcome share 10-15% of documented food cost savings Captures Layer 2 upside. Only kicks in when insights deliver measurable results.

Why This Structure Works

  • Base fee is defensible: Trash savings justify it even without behavior change
  • Compliance is a premium, not included: Regulated customers pay for the additional value they receive
  • Enterprise is a premium, not discounted: Centralization is worth more, not less
  • Outcome share aligns incentives: Mill only earns upside when insights deliver
